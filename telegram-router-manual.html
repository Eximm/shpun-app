Готов к работе

Сначала выберите версию OpenWrt. Мы покажем нужный файл и простые шаги установки.

OpenWrt 24.x OpenWrt 25.x Простая установка Обновления из виджета

1. Узнайте свою версию OpenWrt

Откройте страницу роутера 192.168.1.1. Номер OpenWrt написан на главной странице.

Выберите только свой раздел: OpenWrt 25 или OpenWrt 24. Не скачивайте файлы из другого раздела.
Перед установкой: интернет на роутере уже должен работать.

🟢 У меня OpenWrt 25

Этот раздел только для OpenWrt 25.

Зачем нужна программа-установщик? OpenWrt 25 не разрешает поставить наш файл обычной кнопкой в панели роутера. Программа сама подключится к роутеру и установит всё правильно. Команды вводить не нужно.
  1. 1

    Подключите компьютер

    Подключите компьютер к LAN или Wi-Fi этого роутера.

  2. 2

    Выберите свою Windows

    Для Windows 10/11 нажмите первую кнопку. Для Windows 7/8 — вторую.

  3. 3

    Запустите файл

    Если Windows покажет предупреждение, нажмите «Подробнее», затем «Выполнить в любом случае».

  4. 4

    Нажмите «Установить»

    Программа сама найдёт роутер. Если на роутере есть пароль, программа попросит его ввести.

  5. 5

    Дождитесь сообщения «Готово»

    После этого откройте страницу роутера 192.168.1.1.

🔵 У меня OpenWrt 24

Этот раздел только для OpenWrt 24. Программа из раздела OpenWrt 25 вам не нужна.

  1. 1

    Скачайте пакет

    Нажмите кнопку «Скачать пакет 1.1.8» ниже.

  2. 2

    Откройте панель роутера

    Перейдите на 192.168.1.1.

  3. 3

    Откройте установку программ

    Нажмите System (Система) → Software (Программы) → Upload package.

  4. 4

    Выберите скачанный файл

    Подтвердите установку. Когда она закончится, вернитесь на главную страницу.

После установки

  1. 1

    Найдите код

    На главной странице роутера найдите большой блок Shpun Router. В нём будет короткий код.

  2. 2

    Введите код в приложении

    Закажите услугу Shpun Router и введите код. Роутер сам получит настройки и подключится.

Готово. Ничего настраивать вручную больше не нужно.

Какой роутер подойдёт

Лучше выбрать современный роутер с Wi-Fi 6 и надписью AX3000. На нём VPN обычно работает быстро и без зависаний.

  • Хороший выборСовременный роутер класса AX3000.
  • Проще всегоКупить роутер, на котором продавец уже установил OpenWrt 24 или 25.
  • Не рекомендуемСтарые и самые дешёвые роутеры: VPN на них может работать медленно.

Если что-то не работает

  • Блок Shpun Router не появилсяОбновите страницу роутера. Если не помогло, закройте браузер и откройте страницу снова.
  • Код не принимаетсяВведите восемь латинских букв и цифр из виджета. Дефис можно не вводить.
  • VPN не подключилсяПроверьте интернет без VPN и активность услуги Shpun Router, затем обновите статус в виджете.
  • Скорость стала нижеПроверьте скорость сначала по кабелю, потом по Wi-Fi. На старом роутере VPN может работать медленно.
