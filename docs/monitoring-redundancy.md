# Резервирование в общем статусе

После обновления приложения в настройках обоих зеркал МСК и СПБ:

- включить «Влияет на общий health»;
- указать одинаковую группу резервирования `app-mirrors`;
- сохранить оба узла активными, чтобы мониторинг продолжал проверять их;
- служебные зеркала можно оставить с видимостью «Только админ».

Группа означает, что каждый её узел полностью заменяет остальные для одной функции. Не объединять в неё Core, биллинг, REALITY и XHTTP только потому, что это шлюзы или инфраструктура. Пустая группа сохраняет прежнюю независимую оценку узла. Диагностические узлы, от которых сервис не зависит, можно исключить из общего статуса отдельным флагом.

| Состояние зеркал | Статус группы |
| --- | --- |
| Одно доступно по свежим данным | Работает |
| Оба подтверждённо недоступны | Недоступна |
| Нет доступных, у одного нет свежих данных | Нет подтверждения доступности |

Общий статус учитывает и остальные зависимости и VPN-ноды. Отказ отдельной VPN-ноды среди нескольких не меняет шапку; отказ не менее половины известных VPN-нод ухудшает статус; отказ всех — означает недоступность. Загрузка CPU/RAM/канала остаётся диагностикой администратора.

Инциденты отдельных серверов сохраняются независимо от резервирования. Цвет точки в списке серверов определяется текущим состоянием: свежая успешная проверка — зелёный, офлайн — красный, устаревшие данные — жёлтый, нет данных — нейтральный. Галочка активности означает участие в мониторинге, а не доступность.

Группировка не выполняет DNS-переключение и не проверяет его завершение. Текущий источник доступности — Node Exporter. Успешная проверка метрик не является проверкой входа в кабинет, API, DNS или передачи клиентского трафика. Для проверки автоматического переключения нужны отдельные функциональные пробы с независимых наблюдателей. Группы следует назначать только реально взаимозаменяемым узлам с рабочим маршрутом обслуживания.

Миграция добавляет пустое поле группы, существующие узлы не группируются по имени автоматически. После развёртывания группу МСК/СПБ нужно назначить в админке. Переключение DNS и настройки серверов этой доработкой не меняются.
